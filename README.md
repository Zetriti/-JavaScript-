# Instapro

MVP социальной сети для обмена фотографиями

Фунциональность которую удалось реализовать:
1.Интегрировал верстку списка постов с API
2.Страницу добавления поста
3.Страницу с постами конкретного юзера
4.Функционал лайков.

## Первоначальная оценка

15 часов

## Фактически затраченное время

примерно 20-25 часов

Дополнительные фичи, которые удалось реализовать:
1.Подключён webpack
2.Работа с датой реализована через date-fns
